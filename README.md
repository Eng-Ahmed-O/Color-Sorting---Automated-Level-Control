# Color-Sorting---Automated-Level-Control
This project presents an automated material handling and sorting system developed using TIA Portal and Factory I/O. The system simulates an industrial production line where colored boxes are transported, identified, and sorted using a combination of conveyors, elevators, and a robotic arm.

At the start of the process, boxes move from an upper level through a conveyor system and are transferred via an elevator to a lower level. A robotic arm then performs a pick-and-place operation, sorting the boxes based on their detected color.

Each color follows a specific path:

Blue boxes are diverted to a separate track using a pushing mechanism.

Green boxes continue through the system and are transported by an elevator to the second floor.

Grey boxes are directed to the first floor via the elevator system.

The project demonstrates key concepts in industrial automation, including sensor integration, actuator control, sequential logic design, and real-time system coordination. It also highlights the use of PLC programming to manage complex workflows and ensure efficient material handling within a simulated smart factory environment.
